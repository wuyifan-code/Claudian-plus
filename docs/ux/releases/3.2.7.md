## 目标

所有失败从"一闪而过的浮层"变成"面板里可回看、可操作的一条"；窗口（标签页）能切换、能关闭，关掉的对话随时找得回——**但不恢复常驻徽章行**。

本版包含两组交付：

- **P0 窗口与会话**：用户实际使用中提出的两个问题（见下）。
- **P1 反馈总线**：140 处 chat 面裸 `Notice` 全部迁移到反馈总线。

## 用户提出的两个问题（P0）

> 原话：「任务窗口和历史对话分不清，删掉任务窗口，新增任务之后就找不到以前的历史对话了。以前打开 5 个标签页时，可以点击切换；但现在 5 个标签页满了，就没办法新增了，界面也看不到哪里可以关闭已打开的标签。」

根因（已核实）：

| 症状 | 根因 | 证据 |
| --- | --- | --- |
| 窗口无法点击切换 | `2014d450` 把标签条隐藏后补上了"没有切换入口"——用户要的是能力，不是那排徽章 | `tabCount >= 2` → `true` |
| 看不到关闭入口 | badge 上从来没有 ×，只有中键关闭；徽章一藏就没有任何关闭入口 | `TabBar.renderBadge` |
| 新建后找不到旧对话 | 头部 `+` 是"换掉当前窗口的对话"，不是开新窗口 | `createNewConversation()` |
| 对话没丢但找不回 | 回看入口只剩一个无文字的 history 图标 | 导航行 |
| 三个按钮两语义 | header `+` / `square-plus` / `square-pen` | 两个入口同一方法 |

> 第一次修复试图把徽章行加回来——那是用户明确要求删掉的东西，做法错了。最终形态是头部 chip + popover。

## 任务清单

### A. 标签与会话（P0）

**不恢复常驻徽章行**——这是 3.1.1 的决定，且用户明确要求过删掉。切换与关闭改由头部 chip 承担：

- [x] 头部「窗口 chip」：从第 2 个窗口起出现，显示窗口数；单窗口隐藏
- [x] chip 点开 popover：窗口列表（当前项高亮）、每行一个关闭按钮、点击行即切换
- [x] popover 右键菜单：关闭 / 关闭其他 / 重命名（就地输入框，回车提交、Esc 取消）
- [x] popover 底部「新建任务窗口」；「在此窗口开新对话」留在导航行（常驻可见，不受窗口数影响）
- [x] 点击外部或 Esc 关闭 popover 并把焦点还给 chip
- [x] 标签满额不再弹转瞬即逝的 Notice，改为「先关一个再建」选择器
- [x] 头部 `+` 改为「新建任务窗口」；「在此窗口开新对话」在 popover 与导航行都能到
- [x] 关窗口后发常驻条目「窗口已关闭 · 对话已保存」＋「重新打开」
- [x] 在当前窗口换新对话后发「已开始新对话」＋「回到上一个对话」
- [x] `TabBar` 保持原样并被永久隐藏（`updateTabBarVisibility` 里写明原因）

### B. 总线与宿主（P1）

- [x] `src/shared/feedback/types.ts`：`FeedbackLevel` × `FeedbackKind`（blocked / retryable / info）两轴
- [x] `FeedbackBus.ts`：环形缓冲 100、同 key 5s 去重 ×N、`subscribe`、`emit` + `info/success/retryable/blocked` 语法糖
