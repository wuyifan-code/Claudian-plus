# Claudian Plus 体验打磨路线图（3.2.7 – 3.2.20）

> 计划批准：2026-11-02。起始发布：3.2.6。
> 本文是 14 个版本的**详案与排期**；执行卡见 [`releases/`](releases/)，红线见 [`contract.md`](contract.md)，数字基线见 [`baseline.md`](baseline.md)。
> 状态：**3.2.7 已发布（2026-11-06）**。每版开始时把状态改为 "进行中"，发布后改为 "已发布（日期）"。

## 0. 版本号与节奏

- 主线 **3.2.7 → 3.2.20**，共 14 个 patch；不切 3.3/4.0，不声明兼容性变化。
- 一版 = 一个主题 + 两周（第一周实现、第二周真机 + 发布），周五发版。
- 回归热修优先并入下一版；必须插队时占用下一个号，后续整体顺延。
- 每个 patch 的 CHANGELOG 仍写 `Added / Changed / Fixed`，中英双语同步。

## 1. 北极星与总验收

> 新人不看文档能发出第一句有用的话；任何一次失败都能在面板里看到原因、下一步和重试；用户的工作（草稿、位置、状态）不会丢。

| # | 总验收 | 判定 |
| --- | --- | --- |
| 1 | 全新 vault、0 配置 → 第一条成功回复 ≤ 3 分钟、≤ 3 次点击、不离开面板查文档 | 录屏走查，每版回归 |
| 2 | 面板内 100% 的失败有「原因 + 一个可点的下一步」 | 反馈总线条目 + 抽查 |
| 3 | 草稿、标签布局、阅读位置、界面状态跨重载恢复；破坏性操作 100% 确认或可撤销 | 单测 + 实机 |
| 4 | 68 个 CSS 模块 100% 走 token | ratchet 守卫 |
| 5 | 10 个 locale key 集合一致、占位符一致、无裸字符串 | 守卫测试 |
| 6 | 核心链路可全键盘完成 | 实机 + 焦点断言 |
| 7 | 包体 ≤ 4.0 MB；冷启动模块求值退化 ≤ 10%；1000 轮会话可操作 | `check:performance` + 实机 |

## 2. 现状诊断（实测 2026-11-02，3.2.6）

| 证据 | 实测 | 后果 |
| --- | --- | --- |
| `new Notice(` 调用点 | **299 处 / 46 文件**（其中 chat 面 140 处 / 17 文件） | 反馈转瞬即逝、无历史、无重试、重复弹 |
| 其中直写英文字面量 | **60 处 / 14 文件** | 中文界面里夹英文报错 |
| `localeText(中,英)` | **471 处 / 30 文件**（chat 面 91 处 / 9 文件） | 只分中/英，其余 8 个 locale 回退英文 |
| CSS 模块 | **68 个** | — |
| 间距字面量（padding/margin/gap 带 px） | **628 处**（GenUI 已只剩 1 处，其余 627 处在 chat/settings/toolbar） | 尺度不统一 |
| 圆角字面量 | **53 处 / 19 文件**（GenUI 为 0） | 圆角不统一 |
| 字号字面量 | **184 处 / 45 文件**（GenUI 为 0） | 字阶不统一 |
| `focus-visible` 选择器 | **22 条**（仅 `accessibility.css`） | 键盘可达性未覆盖 |
| `toLocaleString(undefined)` | **4 处** | 跟随系统而非插件 locale |
| 命令 / 默认快捷键 | **16 / 0** | 功能只能靠命令面板发现 |
| 测试文件 / 包体 | **443 个 `*.test.ts` / main.js 3,639,882 B**（预算 5,000,000 B） | 底座够厚，可承载守卫 |
| GenUI 审计 | `flagged = 0`，剩 5 项待真机 | 不是当前最大缺口 |
| smoke checklist | 头部停在 **3.1.1**，条目未勾 | 150+ 条手工验收未闭环 |

**结论**：3.2.x 把"能做到什么"扩到 7 个 provider / 54 个生成式组件 / 记忆 / 笔记嵌入；**外壳**（反馈、导航、上手、文案、尺度）没跟上。14 版只补外壳。

## 4. 逐版本详案

### 4.1 3.2.7 反馈落地：错误有落点（11-09 → 11-20）

- **目标**：所有失败从"一闪而过的浮层"变成"面板里可回看、可操作的一条"。
- **依赖**：无。
- **修复清单**
  1. 新增 `src/shared/feedback/FeedbackBus.ts`：`emit({ level, key, title, detail?, actions?, scope, dedupeMs })`；环形缓冲 100 条；5s 窗口去重并累加 ×N；不落盘。
  2. 新增 `FeedbackHost.ts`：会话面板右下 toast 栈（最多 3 条、可关闭、hover 暂停消失）+ 活动抽屉（按时间倒序、级别过滤）+ 复制脱敏诊断。
  3. 回落：面板未挂载 / 启动阶段 → `Notice`（保留原行为）。
  4. 错误分类：`blocked`（缺配置/权限 → "去设置"深链）、`retryable`（→ "重试"）、`info`（3s 自动消失）。
  5. 迁移 chat 面 140 处（17 文件）：`MessageRenderer`、`InputController`、`ConversationController`、`Tab.ts`、`TabManager`、`ClaudianPlusView`、`fileMenu`、`ImageContext`、`FileContext`、`BangBashService`、`CanvasNeighborsModal`、`ActionableOutputController` 等。
  6. 回合内错误位：失败条目挂在当前回合下方（为 3.2.12 铺路），toast 只做提醒。
  7. 新 CSS 模块 `src/style/components/feedback.css`，注册进 `index.css`。
- **验收**：chat 面 `new Notice(` = 0；同一错误 5s 内一条 + ×N；每条有级别与下一步；`feedbackBus.test.ts`（去重/上限/回退/动作）与 `feedbackHost.test.ts`（焦点/aria-live）全绿；包体 +≤40KB。
- **风险**：总线变成垃圾桶 → 只允许"用户需要知情或动手"的条目进入，级别与 scope 由测试约束。
- **追加（2026-11-06，用户实际使用反馈）**：本版同时修「窗口与会话」——头部「窗口 chip」从第 2 个窗口起出现，点开 popover 可切换、逐个关闭、右键关闭其他/重命名，底部可「新建任务窗口」；满额改为「先关一个再建」选择器；关闭窗口后可一键重开对话；头部 `+` 改语义为「新建任务窗口」。**3.1.1「隐藏常驻标签条」的决定继续有效**：第一批修复曾把徽章行加回来，被用户当场否掉，已撤回。详见 [`releases/3.2.7.md`](releases/3.2.7.md)。

### 4.2 3.2.8 首开与标签：第一分钟（11-23 → 12-04）

- **目标**：新用户从装好到发出第一句，面板内完成；多标签从"隐形"变成"一眼可见"。
- **依赖**：3.2.7（清单里的失败要能重试）。
- **修复清单**
  1. `FirstRunChecklist`：四步（选 provider → 装/指 CLI → 登录+选模型 → 发第一句），每步取 `ProviderRegistry` + CLI resolver + 模型目录的真实状态，一行一个修复按钮，可"稍后"。
  2. 标签 chip：**3.2.7 已交付**（头部 chip + popover：切换、逐个关闭、右键关闭其他/重命名、底部两个新建动作）。本版只补**键盘与计数**：`Mod+Shift+[` / `]` 切换，`Mod+Shift+T` 新建（先确认不与 Obsidian 默认冲突）；等待审批/未读点并入 chip。**仍不恢复常驻徽章行**——3.1.1 的决定继续有效。
  3. 空态统一：`SessionsView`（无会话 → 开始第一个会话）、`ComposerContextTray`（拖入/@ 提示）、记忆面板、GenUI 空态，全部本地化 + 主操作。
  4. 迁移横幅：`.claudian/` 归档提示从 Notice 改为可回看的内联 banner。
  5. 欢迎页：`BlobWelcomeView` 文案本地化 + 最近 3 会话 + 清单入口。
- **验收**：全新 vault 3 步内首条消息；≥2 标签出现 chip 且可键盘开关；空态 100% 有 CTA；无裸英文。
- **风险**：CLI 探测失败不能堵死用户 → 每步可跳过、失败只降级。

### 4.3 3.2.9 文案单通路：十语同权（12-07 → 12-18）

- **目标**：用户可见文案只有一条通路，10 个 locale 真正成立。
- **依赖**：3.2.8（新 UI 直接按 key 写）。
- **修复清单**
  1. 把 `features/chat/**` 的 91 处 `localeText` 全量迁入 `src/i18n/locales/*.json`（en + zh-CN 先齐，其余 8 语按 key 补）。
  2. 守卫：`copy-ratchet.test.ts`（每文件裸字面量计数只减不增，基线入库）、`locale-parity.test.ts`（key/占位符）、`locale-format.test.ts`（禁止 `toLocaleString(undefined)`）。
  3. 清理 60 处裸英文 Notice；`SessionsView` / `InputToolbar` / `ConversationController` 的英文 placeholder 换 key（含 `Search sessions...`、`Search models...`、`No chat sessions yet`）。
  4. 复数约定 `_one/_other` + 轻量 helper（不引入 ICU 依赖）。
  5. 日期/数字：`formatConversationTimestamp`、`formatDurationMmSs` 跟随插件 locale 而非系统 locale。
  6. `localeText` 标 deprecated，只留兼容出口。
- **验收**：`features/chat/**` 中 `localeText` = 0、裸字面量 = 0；10 语 key 齐、占位符一致；zh/en 人工复核记录进 CHANGELOG。
- **风险**：机器初翻质量 → 中英人工校，其余标"待母语校对"，不假装完成。

### 4.4 3.2.10 几何标尺：整容（2027-01-04 → 01-15）

- **目标**：chat / settings / toolbar / modal 与 GenUI 共用一套间距、圆角、字阶。
- **依赖**：3.2.9（避免文案与样式改动互相打架）。
- **修复清单**
  1. 复用 `--claudian-plus-ui-space-*` / `radius-*` / 字阶，扩到非 GenUI 模块；需要时补容器级 token，不新造命名空间。
  2. 迁移顺序：`messages/input/header/sessions-view/status-panel/context-tray` → `settings/*` → `toolbar/*` → `modals/*` → `tabs`。
  3. 守卫：`geometry-ratchet.test.ts` 按文件记录 `padding/margin/gap/border-radius/font-size` 字面量数，只减不增。
  4. 视觉回归：复用 `.context/genui-audit` 的 Chromium 几何测量思路扩到 chat 壳，320/420/620 × 明暗截图归档 `docs/smoke-results/3.2.10/`。
- **验收**：非 GenUI 的间距/圆角/字号字面量降 80%+（基线 627 / 53 / 184）；ratchet 全绿；视觉回归无意外位移。
- **风险**：大范围 CSS 改动 → 每模块一个提交 + 截图对照，禁止"顺手改布局"。

### 4.5 3.2.11 输入与草稿：发得出去、不丢（01-18 → 01-29）

- **目标**：写、带上下文、按发送，这条路上没有暗礁。
- **依赖**：3.2.7、3.2.9。
- **修复清单**
  1. 草稿持久化：`AppTabManagerState.openTabs[].composerDraft?`（≤8KB、800ms 防抖、发送即清、关闭前 flush、旧版本忽略未知字段、**绝不进会话元数据**）。
  2. 能力前置：图片、`/命令`、fork 在入口禁用 + 原因（读 `ProviderCapabilities`），不再点了才报错。
  3. `@` 提及：最近/相关排序、键盘上下 + Enter、空态提示。
  4. 拖拽：整窗高亮 + 非法文件行内原因（替代 Notice）。
  5. 上下文托盘：溢出 "+N"、逐项移除、token 估算、外部目录失效提示。
  6. 模型选择器：搜索/空态本地化；"provider 已不再报告该模型"的弱化态。
- **验收**：重载后草稿逐字恢复；"不支持"类 Notice = 0；三组下拉纯键盘可用；20 项托盘不破版。
- **风险**：写盘抖动 → 防抖 + 关闭 flush；多窗口以"最后写入者赢"并在版本卡写明。

### 4.6 3.2.12 回合状态：可停、可重来（02-15 → 02-26）

- **目标**：从发送到落定全程有状态，答歪了能原地重来。
- **依赖**：3.2.7（回合内错误位）。
- **修复清单**
  1. 回合状态条：`preparing/streaming/waiting-tool/done/failed(+stopped)` 五态，含耗时。
  2. 停止：停止后文本完整、转 `stopped`；provider 支持 steer 时给"继续"。
  3. 编辑重发：`supportsFork || supportsRewind` 时回退到该用户消息再发；否则"作为新回合重发"并明说；都没有则禁用 + 原因。
  4. 失败重试：回合级「重试 / 换 provider / 复制诊断」。
  5. 滚动：上滚停跟随 + "回到最新"胶囊；停止后保持阅读位置。
  6. 消息动作条统一：复制 Markdown / 复制代码 / 重试 / fork（若支持）。
- **验收**：7 个 provider 行为与能力矩阵一致；停止不丢字；重试可复现；滚动不抢位置。
- **风险**：provider 历史绑定语义不同 → 能力矩阵先行，UI 只表达矩阵，不硬编码 provider id。

### 4.7 3.2.13 长对话：一千轮也找得到（03-01 → 03-12）

- **目标**：长会话里"我要找那句话"从翻找变成两次操作。
- **依赖**：3.2.12。
- **修复清单**
  1. 导航器搜索：按问题文本过滤刻度、命中计数、上下跳（走 `turnNavigator/model.ts` 纯函数，不扫 DOM）。
  2. 刻度标识：question / tool / error / bookmark 类型徽标。
  3. 阅读模式：全展开/全折叠 + 逐条折叠记忆；决策点（diff/plan/ask）强制展开。
  4. "加载更早"显式按钮 + 加载骨架；锚点稳定断言。
  5. 会话内查找 `Mod+F`：next/prev + 命中高亮。
- **验收**：1000+ 回合 2 次操作定位；键盘全通；加载不跳变；查找命中可见。
- **风险**：虚拟窗口与搜索的交互 → 先定位到 model 索引，再交给 `MessageRenderWindow` 展开。

### 4.8 3.2.14 会话管理：像文件一样可管（03-15 → 03-26）

- **目标**：会话列表达到文件浏览器的可信度。
- **依赖**：3.2.8（标签 popover）、3.2.13。
- **修复清单**
  1. 分组：今天 / 7 天 / 更早；置顶；归档（隐藏 + 可恢复）。
  2. 批量：多选、批量删除（确认 + 撤销）、批量归档。
  3. 行内：重命名、provider 徽章、消息数、最后活动时间。
  4. 标签 popover：关闭/关闭其他/重命名（与 3.2.8 收口）。
  5. fork/rewind：入口按能力显隐；后果说明（"从这条消息分支，原会话保留"）；失败文案本地化。
- **验收**：危险操作 100% 确认或撤销；1000 条会话首屏 < 100ms；裸英文 = 0。
- **风险**：删除不可逆 → 走 Obsidian trash + 撤销条。

### 4.9 3.2.15 设置与 provider：配置不再是考古（03-29 → 04-09）

- **目标**：新 provider 不看文档能配通，错了知道错在哪。
- **依赖**：3.2.7、3.2.9。
- **修复清单**
  1. 每 provider 一个向导：「检测 CLI → 路径 → 登录 → 模型 → 发一句测试」，每步可跳过。
  2. 健康面板：状态 / 最近失败 / 耗时 / 脱敏诊断复制。
  3. 行内校验：路径、端口、模型 ID、JSON 配置（替代 Notice）。
  4. 分区"恢复默认" + "最近改动"清单。
  5. 设置搜索：跳转 + 高亮 + 无结果引导（拼音/别名可选）。
  6. 能力矩阵：当前 provider 支持/不支持项在设置页可见。
- **验收**：新 provider ≤5 分钟配通；校验全部行内；Notice 型校验 = 0；搜索命中可跳转高亮。
- **风险**：向导要容忍"CLI 在但没登录"等中间态，不为难用户。

### 4.10 3.2.16 生成式界面：收口（04-12 → 04-23）

- **目标**：把审计剩下的"最后 5 项"从"我还没看"变成"有图有数"，并补笔记嵌入手感。
- **依赖**：3.2.10（token）、3.2.9（文案）。
- **修复清单**
  1. 真机 5 项逐条收口：暗色对比、第三方主题、NoteCard/Image/Mermaid 真数据、度量脚本误报、3 段未逐行复核 CSS。

## 5. 横向机制

### 5.1 反馈总线 API（3.2.7 落地）

```ts
type FeedbackLevel = 'info' | 'success' | 'warning' | 'error';
interface FeedbackAction { id: string; label: string; run(): void | Promise<void>; }
interface FeedbackEntry {
  id: string; level: FeedbackLevel; key: string;
  title: string; detail?: string; actions?: FeedbackAction[];
  scope: 'chat' | 'settings' | 'startup'; count: number; at: number;
}
class FeedbackBus {
  emit(input: Omit<FeedbackEntry, 'id' | 'count' | 'at'> & { dedupeMs?: number }): void;
  subscribe(fn: (state: { entries: FeedbackEntry[]; unread: number }) => void): () => void;
  openLog(): void;
  copyDiagnostics(): Promise<void>;
}
```

数据流：`调用点 → emit → 当前宿主（chat/settings）→ toast + 抽屉`；无宿主 → `Notice` 兜底。条目只在内存，不落盘。

### 5.2 文案单通路

- 用户可见字符串一律 `t()`；`localeText` 3.2.9 标 deprecated、3.2.20 前删除。
- 守卫：裸字面量计数只减不增；10 语 key/占位符一致；复数用 `_one/_other` 显式 key。

### 5.3 几何标尺

- 复用容器级 `--claudian-plus-ui-space-*` / `radius-*` / 字阶；`geometry-ratchet.test.ts` 按文件锁上限。
